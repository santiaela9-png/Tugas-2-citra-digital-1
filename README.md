# Tugas-2-citra-digital
# Image Colorization menggunakan Deep Learning

# Deskripsi
Proyek ini merupakan implementasi pengolahan citra digital untuk mengubah gambar grayscale menjadi gambar berwarna menggunakan Deep Learning dan OpenCV DNN.

# Teknologi
- Python
- OpenCV
- NumPy
- Matplotlib
- Pillow

# Metode
Image Colorization menggunakan model Deep Learning yang memprediksi kanal warna pada ruang warna Lab.

# Tahapan
1. Membaca gambar.
2. Mengubah gambar menjadi grayscale.
3. Melakukan prediksi warna menggunakan model AI.
4. Menampilkan perbandingan gambar asli, grayscale, dan hasil colorization.

# Cara Menjalankan
1. Instal library yang dibutuhkan.
2. Simpan gambar di folder `gambar`.
3. Jalankan program Python.
4. Lihat hasilnya di folder `hasil`.
